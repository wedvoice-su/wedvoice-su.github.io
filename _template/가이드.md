# 새 사이트 만드는 법

이 폴더(`_template`)는 새 사이트를 시작할 때 복사하는 기본 틀이에요.
이름이 `_`로 시작하는 폴더는 사이트에 올라가지 않아요.

## 폴더 구조

```
index.html                 결혼식 음악 테스트 첫 화면 (허브)
groom/ lovely-bride/ hand-in-hand/ sing-for-you/   입장곡·축가 테스트 페이지 (주소)
song/                      입장곡·축가 테스트 코드 (song.js, song.css)
shared/                    모든 사이트 공통
  brand.css                  색, 글꼴, 첫 화면, A/B 질문, 결과 카드, 버튼
  common.js                  사이트 목록, 로고·서명, 결과 공개, 이미지 저장, 링크 복사
  img/                       로고, 아이콘, 링크 미리보기 이미지
_template/                 새 사이트 기본 틀 (사이트에 안 올라감)
```

## 순서

1. `_template` 폴더를 복사해서 새 사이트 이름으로 바꿔요.
   - 이름이 곧 주소예요: `wedvoice-su.github.io/새이름/`
   - 영어 소문자와 `-`만 쓰고, 다른 사이트 주소에서 짐작하기 어렵게 지어요. (예: `lovely-bride`, `hand-in-hand`)
2. `index.html`의 TODO: 사이트 이름과 한 줄 설명을 바꿔요.
3. `app.js`의 TODO: 질문, 결과, 문구를 이 사이트 내용으로 바꿔요. 이 사이트만의 스타일은 `app.css`에 넣어요.
4. `shared/common.js` 맨 위 "사이트 목록"에 한 줄 추가해요.
   - 릴스 댓글로 링크를 보낼 사이트면 `reel`에 릴스 주소를 넣어요. 다른 사이트의 버튼이 이 사이트 대신 릴스로 가요.
   - 주소를 공개하는 사이트면 `direct: true`를 넣어요.
5. 화면을 확인하고 푸시해요.

## 지킬 것

- `shared/` 파일을 고치면 모든 사이트가 바뀌어요. 한 사이트만 바꾸고 싶으면 그 사이트 폴더의 파일을 고쳐요.
- 문구는 모두 사회자님이 직접 확인한 뒤에 올려요.
